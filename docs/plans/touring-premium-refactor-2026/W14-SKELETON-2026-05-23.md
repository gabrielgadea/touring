## First achievable slice (next session)

**W14.1 + W14.2 + W14.3 = tier foundation (no external deps)**:

1. Add `[features]` block to workspace Cargo.toml:
   ```toml
   tier-free = []
   tier-standard = ["tier-free"]
   tier-premium = ["tier-standard"]
   tier-enterprise = ["tier-premium"]
   default = ["tier-free"]  # opt-in escalation
   ```
2. Create `crates/touring-license/` (NEW crate) with JWT validation
   stub — accepts `Some(license_jwt) → Tier` or `None → Tier::Free`.
   `ed25519-dalek` already in workspace deps (verify).
3. Add `cfg!(feature = "tier-premium")` gates in 2-3 specific functions
   (e.g., advanced MCTS rollouts in `touring-cognitive`) as demonstration.
4. Tests for license parse + tier escalation.

Estimated: 1.5 sessions of focused work. Delivers a working tier model
that the rest of W14 (registry/SSO/SIEM/distro) layers on top of.

## Commercial decisions needed BEFORE W14 can be "complete"

- **License keypair**: who holds the ed25519 private key? Gabriel personally?
  Org-level?
- **Tier feature mapping**: what specifically does each tier unlock? (Plan
  doc says "telemetry free/std ON, premium/ent OFF" but a full feature
  matrix is undocumented.)
- **Pricing**: not engineering, but blocks W14.10 marketing.
- **Trial period**: free/standard difference? Standard = paid? How is the
  trial license issued?
- **Open-core line**: which features are open-source forever vs proprietary?

Without these decisions, W14 implementation can scaffold the **mechanism**
but cannot ship the **policy**. The first achievable slice (W14.1+W14.2+
W14.3) builds the mechanism for whatever policy is later decided.
