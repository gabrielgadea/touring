## First achievable slice (next session)

**W13.1 partial — `touring-foundation` README + `#![warn(missing_docs)]`**:

1. Create `crates/touring-foundation/README.md` (~150 LOC) covering purpose, public API surface (cited from `touring index find`), MSRV, license, docs.rs link.
2. Add `#![warn(missing_docs)]` to `crates/touring-foundation/src/lib.rs`.
3. Run `cargo doc -p touring-foundation --no-deps` and add `///` docstrings to top N pub items until 0 warnings (budget: 2-3h focused work).
4. Persist lesson + RL + add to CHANGELOG.

This is **idempotent** and **incremental** — each session can add one crate.
13 productive crates × ~2h each = ~26h of focused work spread across many
sessions. Far more achievable than the 8-10 day "full W13" estimate.

## Deferred external integrations

Until Gabriel decides on the registry + signing strategy:

- **Registry choice**: crates.io (public) vs internal registry (CFR-style)?
  W13.6 cannot proceed without this decision.
- **Sigstore identity**: Gabriel's personal sigstore account? Org-level?
  W13.5 cannot proceed without this.
- **release-plz config**: requires `release-plz.toml` per workspace +
  GitHub Actions secret for the publish token. Both depend on registry choice.

Until then, the documentation work (W13.1, W13.2) can proceed independently.
