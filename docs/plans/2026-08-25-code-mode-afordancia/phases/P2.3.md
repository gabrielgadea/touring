# P2.3 — Calibração das 5 classes (20 prompts reais)

**Pergunta** ([RETOMAR-AQUI](../RETOMAR-AQUI.md) §P2.3): a matriz de roteamento está
certa — ou a fronteira T2/T3 é chute? Sem calibração, P3 e P4 ficam sem critério de
substituição.

## Método

- **Corpus**: 20 prompts substantivos de 8 sessões reais deste workspace (cap 8/sessão),
  **1.312 tool calls** extraídas dos transcripts CC. Instrumento:
  [calibration_p23.py](../calibration_p23.py); dados:
  [calibration_p23.json](../data/calibration_p23.json).
- **Classificador**: determinístico, *segment-aware* — separa por `; && || |`, classifica
  cada segmento e decide por precedência **T4 > T3 > T0 > T2** (um composto é da sua
  operação mais forte). Tokens estruturais de shell (`{`, `for`, `do`…) e atribuições
  `VAR=` são transparentes.
- **Taxonomia** (a definição original não estava persistida — este relatório a fixa):
  **T0 execução** (veredito: cargo/pytest/guards/`touring run`) · **T1 iteração cega**
  (byte-idêntico anterior, o G6 mede) · **T2 informação** (lê estado: grep/cat/find/ls,
  Read, git status) · **T3 instrução** (altera estado: git commit, mkdir, daemon-ctl,
  memory store) · **T4 escrita verificável** (Write/Edit, `cat >`, `sed -i`, open(w)).

## Distribuição medida

| classe | chamadas | % | leitura |
|---|---|---|---|
| T4 escrita verificável | 404 | 30% | ⅓ das chamadas — **a recusa do code-mode-obrigatório está certa** (taxar escrita taxa o caso comum) |
| T2 informação | 402 | 30% | a classe-alvo da matriz — empatada com T4 como a maior |
| T3 instrução | 302 | 23% | nunca colapsa — efeito no mundo |
| T0 execução | 201 | 15% | vereditos — não colapsa |
| T1 iteração cega | 3 | ~0% | **o G6 já suprime** — não justifica classe própria na matriz |

## Vereditos

1. **A matriz (grep/cat/find colapsam; ls/wc/sed-n passam) é VALIDADA pela medição.**
   Das T2-Bash: 104 nas classes colapsadas
   vs 166 passando (ls/wc/sed-n/python-inline/
   compostos). Nenhuma evidência para mover ls/wc/sed-n para dentro do colapso.
2. **A fronteira T2/T3 não é chute**: 92% das chamadas (1.212/1.312) classificam sem
   fronteira; as 100 fronteiras residuais são 2 padrões legítimos
   (python inline — o corpo decide; veredito de gate) + ruído de banner `echo` que não
   muda a classe. **Revisão humana da amostra: 12/12 de concordância** na classe atribuída.
3. **Fix `cat`-redirect era OBRIGATÓRIO — aplicado nesta fase.** 27
   escritas via heredoc (`cat > f`/`cat >> f`) seriam negadas como "inspeção cat" pelo
   `scan_class_of` (que lia só o prefixo): **20,6% de erro sobre o universo que a matriz
   pegaria**, num modo que nega na 1ª chamada. Fix: o primeiro operando real decide
   (flags e seus argumentos transparentes) — se começa com `>`, não há arquivo de leitura,
   `scan_class_of` devolve `None`. Teste `cat_com_redirect_e_escrita_nao_inspecao`
   **provado por mutação** (remover o braço reprova 3 casos; restaurar, 398/398 verde).
4. **T1 fora da matriz**: 3 ocorrências em 1.312 — o G6 (TTL + hash) já cobre.
