# Specs H1-H15 — complementação dos hooks

## TL;DR

15 handlers novos, 1 por spec. Cada spec é autocontida. Padrão único: **subprocess fire-and-forget** (nunca import Rust direto), JSON canônico no `additionalContext`, latência budget <100ms p95.

**VGP rodada** (31/08 18:53): 10/15 subcomandos CLI JÁ existem; 4 precisam ser criados em F1.5 (subtarefa adicional). Vou listar a lacuna em cada spec.

## Convenções comuns (todos os 15)

```bash
# Padrão de invocação (arch:generator-hooks-integration:pattern)
touring <subcmd> <args> --json | jq '<filter>'

# Exemplo: H1 quality
touring-quality score <file> --json | jq '{delta_quality, blast_radius}'

# Latência budget: <100ms p95 (medida em F2)
# Fail-open: timeout 5s, erro de parse → stdout vazio, hook termina OK
# additionalContext: JSON único, campos tipados
```
