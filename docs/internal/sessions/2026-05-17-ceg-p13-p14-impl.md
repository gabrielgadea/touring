## 1. P1.3 — AST-based forbidden-call detection (hybrid 11-language)

New module `crates/touring-hooks/src/shared/forbidden_patterns.rs`.

| Language | Method | Reason |
|----------|--------|--------|
| JS, TS, Python, Ruby, Rust, Php, Elixir | **AST** (`scan_source` + `FORBIDDEN_*` `PatternSet` consts) | ast-grep grammar present, ABI-14 OK |
| Go, Shell | **substring fallback** | tree-sitter 0.25 grammar is ABI-15 → panics ast-grep-core 0.36 (B-FUZZ-001/002) |
| Perl, R | **substring fallback** | no ast-grep grammar in ast-grep-language 0.36 |

- Entry point `ast_forbidden_scan(SandboxLanguage, &str) -> Vec<String>` — dispatches via `sandbox_lang_to_polyglot` (AST-capable?) → AST path or substring fallback.
- Collateral: `Lang::Elixir` added to `crates/touring-code/src/polyglot/lang.rs` (ast-grep ships the Elixir grammar; the `Lang` enum lacked the variant).
- **No ast-grep version bump** — 0.36 already ships the 7 AST grammars (the 0.42 modernization is the separate tree-sitter-ABI wave).

## 2. P1.4 — ctx_execute forbidden-call ENFORCEMENT (phased WARN→ENFORCE)

`crates/touring-server/src/tools/ctx_execute_tools.rs`:

- `ForbiddenCallPolicy` enum — `Off` | `Warn` | `Block`. **Default `Warn`** (the chosen phased rollout, R1 mitigation). `from_env()`: `TOURING_CEG_FORBIDDEN_ENFORCE=1`→`Block`, `TOURING_CEG_FORBIDDEN_OFF=1`→`Off`, else `Warn`.
- `CtxExecuteError::ForbiddenCalls(Vec<String>)` — returned by the gate in `Block` mode.
- Enforcement gate in `ctx_execute_impl` (after detection, before sandbox): `Block` + forbidden non-empty + `allow_forbidden != Some(true)` → reject. `Warn` → run + `[CEG WARNING]` on stderr. `allow_forbidden` is the explicit per-call override (threaded through `CtxExecuteParams` + `tools_ctx_execute.rs`).
- **Fail-open**: `run_forbidden_scan` wraps `ast_forbidden_scan` in `catch_unwind` — a grammar panic never breaks execution.

## 5. Plan corrections (from the scout, confirmed)

- `detect_forbidden_calls` was substring-only, 3/11 languages, advisory — superseded by `ast_forbidden_scan`.
- `AstGrepRiskSignalLayer` is a pre-read `SignalLayer` — wrong abstraction; the reuse symbols are `scan_source`/`PatternSet`/`PatternEntry`.
- Polyglot home is `touring_code::polyglot` (the `touring-ast-polyglot` shim re-exports it).
- P1.3 "AST for all 11" is not literally achievable — Perl/R have no grammar; Go/Shell hit the ABI-15 panic. Hybrid is the honest design.
