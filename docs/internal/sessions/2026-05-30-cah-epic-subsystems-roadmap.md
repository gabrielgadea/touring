## 0. Executive Summary

A **Code Agent Harness (CAH)** is the deterministic substrate that *drives* an LLM agent — **not** the model, **not** the serving layer. Cursor, Devin/Cognition, and Claude Code are model-agnostic orchestration layers: they do **not** ship their own proof assistant, speculative-decoding stack, or vision model — those belong to the model endpoint. The elite differentiators a *harness* can genuinely own are exactly the territory Touring can claim:

1. a **durable + calibrated action world-model** (survives restart, feeds prediction),
2. a real **verifier-in-the-loop** (per-claim SMT discharge, not lexical heuristic),
3. **enforced transactional concurrency** for parallel agents,
4. a **hash-pinned self-attesting contract** (the constitution as a runtime object).

**Total in-scope epic effort ≈ 67 engineer-days** (4 subsystems; +12 ed optional Lean tier; ES5 is a confirmed non-goal). Shipping them flips **5-6 PARCIAL rows → CONFORME**, pushing in-scope conformance from ~78% toward the **low-to-mid 90s%**.

**Highest-leverage first move: ES4 P1 — persist + warm-load the action world model (3 ed).** Best ROI in the roadmap: the online draft→predict→learn loop is *already wired*; the only defect is that `LearnedOutcomeModel` (which already derives `Serialize`/`Deserialize`) is never written to disk, so a fresh daemon predicts flat 0.5 despite 64+ durable observations sitting unused in `bash_outcomes`. Plumbing, not invention.
