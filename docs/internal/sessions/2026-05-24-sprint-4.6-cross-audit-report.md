## Phase 5 deep dive — FIX & POTENTIALIZE

The cross-audit found ONE pre-existing error in scope: `ropey::Rope::byte_to_char` OOB
panic captured by Sprint 4.5 `panic_log` infrastructure 14 minutes after the post-bash
fix was deployed. **Sprint 4.5+4.6 infrastructure proved its worth immediately** — a
bug invisible for weeks became loud-and-located in minutes.

### Root cause

Thread `touring-project-actor` (uptime 866s, PID 38936) called
`self.rope.byte_to_char(byte_idx=84877)` where `rope.len_bytes()=84279`. The 598-byte
overflow indicates a stale byte_idx — likely computed against a previous revision of
the document and applied after the underlying buffer shrank (cross-actor coordination
or deferred edit application).

Panic location: `ropey-1.6.1/src/rope.rs:635:41`. Callsite: `touring-code/src/ast/document.rs`
in `edit()` (lines 125-128) or `slice_bytes()` (lines 167-168).

### Fix applied via REGRA #0 potentialization

`Document::edit()` and `Document::slice_bytes()` now defensively clamp `start_byte` and
`old_end_byte` to `rope.len_bytes()` before invoking any rope method. When clamping
fires, `tracing::warn!(target: "touring_code::ast::document", ...)` emits a structured
log so the upstream coordination bug remains diagnosable. The InputEdit contract is
preserved: a no-op edit at end-of-rope is well-defined and tree-sitter accepts it.

### Tests added (5 new sprint_4_6_* tests in `tests::` mod)

| Test | Asserts |
|---|---|
| `sprint_4_6_edit_clamps_oob_start_byte_no_panic` | `edit(1000, 1000, "world")` on 5-byte rope clamps to (5,5,"world") instead of panicking |
| `sprint_4_6_edit_clamps_oob_old_end_byte_no_panic` | `edit(2, 9999, "Y")` on 5-byte rope clamps old_end to 5 |
| `sprint_4_6_edit_clamps_inverted_oob_no_panic` | `edit(100, 50, "Z")` clamps inverted-OOB to (3,3,"Z") via `.max(safe_start)` invariant |
| `sprint_4_6_slice_bytes_clamps_oob_no_panic` | Both-OOB returns ""; inverted-OOB returns "" |
| `sprint_4_6_edit_inbounds_path_unchanged` | Regression guard: in-bounds edit `(6,11,"Rust")` on "hello world" still yields "hello Rust" — clamp is a no-op for valid input |

All 5 pass: `cargo test -p touring-code --lib sprint_4_6` → `5 passed; 0 failed`.
